# hh-client-vault
Umbrella repo for client deliverables and internal projects.

## Directory Structure

*   **`clients/`**: Dedicated folders for work performed for external clients (e.g., J&M Organics, 018 Studios).
*   **`projects/`**: Dedicated folders for internal initiatives and independent projects (e.g., Gas Motor Show).
*   **`templates/`**: Reusable code templates and snippets.
*   **`docs/`**: General documentation and guides.
