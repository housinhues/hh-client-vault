# hh-client-vault
Umbrella repo for client deliverables and internal projects.

## Directory Structure

*   **`clients/`**: Dedicated folders for work performed for external clients. This includes active clients (e.g., J&M Organics, Ogleit) and archives of past clients (e.g., 018 Studios).
*   **`projects/`**: Dedicated folders for internal initiatives, one-time projects, or personal endeavors (e.g., Gas Motor Show, Vuks).
*   **`partners/`**: Dedicated folders for long-term collaborations or strategic alliances (e.g., Siya).
*   **`internal/`**: Dedicated folders for internal tools, systems, or overarching initiatives (e.g., Talent Management).
*   **`templates/`**: Reusable code templates and snippets.
*   **`docs/`**: General documentation and guides.
