02 — Build Anatomy: What Was Constructed

Landing Page

true-organics.html · Last modified 4 Jun 2026

Design Token System

12 CSS custom properties defined at :root — 5 green tones, 3 orange/gold tones, cream background, 2 text shades. Every visual decision derives from these tokens. Changing one variable updates the entire site.

Typography Architecture

Playfair Display (display/headers) paired with DM Sans (body/UI). Deliberate pairing — editorial authority meets modern legibility. Type scale built with clamp() for fluid responsiveness across screen sizes.

Fixed Nav with Backdrop Blur

position:fixed with backdrop-filter:blur(16px) and rgba transparency — stays readable over any content as user scrolls. z-index:200 ensures it sits above all content layers.

Hero Section Engineering

Full-viewport hero with dual radial gradient background — layered depth without images. CSS Grid two-column layout. fadeUp keyframe animation on load. Responsive collapse at mobile breakpoint.

Multi-Channel CTA System

4 distinct call-to-action buttons — WhatsApp (green #25D366), Facebook (#1877F2), Start Now (brand orange), Email (ghost). Each with unique hover states, box-shadows, and transform animations. Not generic — channel-specific.

Product Card Components

Reusable .pc component class with featured variant. Price display, tag system, grid layout. Navigable via anchor: #products.

SEO Infrastructure

Title tag, meta description, and keyword meta tag all configured. "True Organics - 100% Organic Products | South Africa" — search engine ready from day one.

Referral Link Integration

https://trueorganics.life/join-us/TO10700879953 embedded as primary CTA throughout — every "Join Now" action routes through John's personal referral, directly building his downline.

Client Management Dashboard

johnz-true-organics-brief-v2.html · Jun 2026

React State Architecture

Built with React 18 (CDN) — useState and useEffect managing all data. Full tab system: Overview, Financial, Scope, Flags, Timeline, Next Steps, Files. No page reloads — single-page application.

Client Data Model

Structured JSON object containing: client profile, financial summary, payment log, scope items with status, risk flags with severity, project timeline, next steps, file index. Not a note — an operational record.

Payment Ledger

Every payment logged with date, amount, method, and note. Running total computed from entries. Foundation for this exact cost defense document.

Risk Flag System

Three-tier severity model: high / medium / low. Each flag is a structured object — not free text. Colour-coded: red, amber, grey. Built to surface issues before they become problems.

Scope Tracker

8 deliverable items tracked with status: done / in-progress / pending / not-started. Status badges colour-coded. Each item has a note field. Built as a living document, not a static list.

File Reference Index

7 linked assets: landing page, client brief JSX, WhatsApp export, business slides PDF, brand profile PDF, CIPC portal link, live domain. All accessible from one interface.
