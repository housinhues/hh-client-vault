# Dashboard Build — Prep Guide
### Complete before 10 AM tomorrow

## STEP 1 — Set Up Google Drive Folders

Create one master folder called **HH — Social Content**

Inside it, create 5 subfolders:
- `01_College`
- `02_Cleaning Service`
- `03_Culture & Art`
- `04_Media Production`
- `05_Housing Hues`

Each folder is where raw content (photos, videos) gets dropped before the dashboard picks it up.

---

## STEP 2 — Set Up Metricool

Go to **metricool.com** → create a free account if you don't have one.

Connect all 5 platform accounts:
- Facebook Page (not personal profile)
- Instagram Business Account
- TikTok Business Account
- YouTube Channel

> **Important:** Instagram and TikTok must be Business/Creator accounts — not personal. If they're personal, switch them before connecting. This is a platform requirement, not Metricool's.

---

## STEP 3 — Confirm Your NVIDIA API Key

You already have an NVIDIA API key. Locate it before the session — you'll need to paste it into the dashboard during the build.

If you can't find it: **build.nvidia.com** → sign in → API Keys.

---

## STEP 4 — Prepare a Content Brief Per Account

For each of the 5 accounts, have a one-line answer to these 3 questions ready:

1. **Who is the audience?**
2. **What's the main goal of the account?** (awareness, leads, community, etc.)
3. **What tone?** (formal, energetic, editorial, conversational, etc.)

This feeds directly into the AI content profiles in the dashboard. Without this, the AI generates generic content.

---

## STEP 5 — Confirm Platform Access

Make sure you have login access or admin access to all 5 accounts before the session. Nothing kills a build faster than a password reset in the middle of it.

Platforms to confirm:
- [ ] Facebook Page — admin access
- [ ] Instagram Business — login ready
- [ ] TikTok Business — login ready
- [ ] YouTube — channel access
- [ ] Google Drive — already connected

---

## STEP 6 — Drop Test Content Into Each Drive Folder

Put at least 1–2 images or a short video into each subfolder.

This lets us test the full pipeline during the build — Drive detects content → AI writes copy → post queues to Metricool → distributes to platforms.

Without test content the pipeline has nothing to run on during the session.
